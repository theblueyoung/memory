# 추억 앱 (가제: 응답하라 1982)

친한 친구들과 실물 사진첩, 교환일기, 음악을 나누는 레트로 앱의 시안입니다.

## 시안 파일 (브라우저에서 열어 보는 단일 HTML)
- `prototype/eungdap-1982.html` : 현재 시안. 미니홈피, 방명록, 사진(스캔 연출), 음악, 다이어리(교환일기), 삐삐번호.
- `prototype/old-drawer-v1.html` : 첫 번째 시안(오래된 서랍). 카세트 표지와 앨범.

## 메모
- 시안의 사진, 친구, 일기는 모두 가짜 예시이고 스캔 보정은 화면 연출입니다.
- 음악은 파일 재생이 아니라 스트리밍 링크로 공유하는 방향입니다(저작권).
- 이름("응답하라"), 싸이월드 고유 용어는 출시 전에 새로 정해야 합니다.
